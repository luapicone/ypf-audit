# Conversor de auditorías por elemento
Sitio estático (sin build). Subir el Excel de auditoría (Norma, Punto, Porcentaje) y descargar el % por elemento.
- mapping.js: matriz de "Comparativa SGEO FINAL" normalizada.
- calc.js: motor de cálculo. app.js: lector de entrada (ajustable al formato real) e interfaz.
- Vercel: importar la carpeta, Framework "Other", sin build.
